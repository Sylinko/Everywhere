# SDK wire fixtures

Error files contain arrays of typed `ErrorFixture` entries. `body` contains JSON;
`rawBody` preserves empty, plain text, HTML, or malformed payloads. The same entry
can name multiple compatible clients without duplicating payload data. Tests assert
faithful status/body transport and production normalization. Each error entry also specifies expected category and recovery advice.

`source` entries are transcribed from mockllm commit
`4d4b1942ef8dc22c18f495f280109df1d621fdf6`. Attribution and the selected MIT license
are in `mockllm-LICENSE.txt`. `synthetic` entries are Everywhere's gateway and
parser counterexamples, not claims about any real provider.

Add sanitized real API captures as a new JSON array with `provenance: "observed"`,
`observedAt`, and `notes` describing provider/service, SDK version, request shape,
and sanitization. Never include credentials or user documents. Add only a case that
distinguishes a new behavior, with a stable ID and applicable clients.

`responses-tool.sse` is an independently written valid Responses tool transcript:
MockServer 8.0.0's built-in Responses codec lacks the required `call_id`.
The fixture provides a valid-ID control and is mutated for absent/null/empty IDs
and malformed arguments. Parallel missing-ID regressions also use the raw codec.
These tests verify the MEAI compatibility patch and inspect the next HTTP request
for matching function-call/result IDs.
Other valid text/tool streams are generated by MockServer's provider codecs.

`openai-text-usage.sse` is an independently written valid Chat Completions stream,
including a usage-only chunk after the explicit stop reason. MockServer 8.0.0's
Chat streaming codec omits usage even when the expectation supplies it.
The raw Ollama done/usage payload and Responses incomplete/failed events in
`SdkBoundaryTests` are also synthetic wire data, not real-provider captures.

`SdkStreamLifecycleTests` writes minimal valid event prefixes in C# for all six
paths. The same prefix is served as a normally framed body without a terminal
event, an unterminated HTTP chunk followed by disconnect, or a pending chunked
body. These cases separately establish missing completion evidence, a genuine
transport failure, cancellation, and early enumeration disposal. Observers only
forward real SDK reads and record content/stream disposal; they do not synthesize
SDK exceptions or fabricate response data.
